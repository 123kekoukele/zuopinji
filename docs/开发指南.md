# 开发指南

## 目录

- `source/Back/hadluo-server` — Maven 后端
- `source/Front/hadluo-vue` — 用户端
- `source/Front/hadluo-vue-admin` — 管理端

## 首次

```bash
# 后端
cd source/Back/hadluo-server
mvn spring-boot:run -Dspring-boot.run.profiles=prod

# 前端（各开终端）
cd source/Front/hadluo-vue && npm install && npm run serve      # :8082
cd source/Front/hadluo-vue-admin && npm install && npm run serve # :8081
```

需先启动 MySQL、Redis、MinIO。

## 编译

```bash
cd source/Back/hadluo-server && mvn package -DskipTests
cd source/Front/hadluo-vue && npm run build
cd source/Front/hadluo-vue-admin && npm run build
```

Windows 一键脚本见 `windows-deploy/07-开发与构建/`。
