# MinIO 本地部署

1. 下载 Windows 版 MinIO：https://min.io/download
2. 启动示例：

```bat
set MINIO_ROOT_USER=hadluo
set MINIO_ROOT_PASSWORD=HadluoMinio@2026
minio.exe server D:\minio-data --console-address :9001
```

3. 浏览器打开 http://127.0.0.1:9001 创建桶 `hadluo-files`
4. 或使用项目根目录 `docker-compose.minio.yml`（需 Docker）

配置与 `source/Back/hadluo-server/src/main/resources/application-prod.yml` 一致。
