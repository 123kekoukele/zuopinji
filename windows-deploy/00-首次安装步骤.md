# 首次安装（Windows）

1. 解压到英文路径，如 `D:\hadluo-open\`
2. 安装 JDK 21、MySQL 8、Node、Maven、Redis、Nginx（见 01-运行环境）
3. 复制 `local-paths.example.bat` → `local-paths.bat`
4. 运行 `0-检查环境.bat`
5. 导入 `../database/hadluo-lvyou.sql` 或运行 `02-数据库/import-database.bat`
6. 启动 Redis、MinIO、后端、Nginx（06-启动脚本）
7. 访问 http://localhost/ 与 http://localhost/admin/
